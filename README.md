# Vela

Static site for Vela. Built with a single self-contained `index.html`, `support.js` runtime, and `assets/` (images/video).

## Local preview

Just open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Deploy (GitHub Pages)

Pages is served from the `main` branch root. Enable it under Settings → Pages → Source: `main` / `/ (root)`.
